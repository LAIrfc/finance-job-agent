  五、Q&A

  Q1：本次招聘对象是哪些同学？

  本次招聘主要面向2027届海内外高校应届毕业生，应聘人员须为最高学历毕业后首次就业。其中，国（境）外院校留学人员毕业时间要求为2026年7月至2027年6月，且须取得国家教育部的学历认证。

 

  Q2:本次校园招聘的工作地点都是在北京吗？

  集团公司、10家成员单位及其下属机构参与本次校园招聘，工作地点遍布全国，详见招聘网站。

 

  Q3:本次校园招聘的整体时间安排是什么？

  1）在线投递：简历通道整体开放时间为2026年8月1日至2027年4月25日。

  其中：集团本级岗位2026年10月中旬截止投递；各单位总部和部分省级机构本级2026年11月中下旬截止投递。

  2）简历筛选：时间安排与在线投递时间一致。

  3）笔试：分批次陆续开展。综合类和科技类设置差异化笔试试题。

集团本级岗位仅组织2026年10月一个批次的笔试。如有投递意向，请合理安排投递时间，并建议将该岗位设置为第一阶梯志愿。后续如收到笔试通知，请按时参加。

  4）面试：分批次陆续开展。

  5）签约及录用：分批次陆续开展。

  Q4：简历投递方式有哪几种？

  本次招聘统一采取网上报名方式，可通过招聘官网Image: 1790230347198475.png或“人保招聘”小程序投递。

 

  Q5：什么时间截止网申？

  网申截止时间参见Q3整体时间安排。需要注意的是，每个岗位招满即停，关停岗位将不再在招聘平台中显示，请应聘者合理安排投递时间，尽早投递。

 

  Q6：可以申请几个校招职位？

  每位应聘者可根据意愿申报两个阶梯岗位（以投递时间顺序确定志愿优先次序，第一志愿淘汰后方可进入第二志愿）。同一家机构（如同一家子公司总部、同一家省公司本级、同一家市级公司）最多可申请1个岗位。

  同意调剂的，还可以在网申页面填写意向单位和意向工作地点，后续会根据学生调剂意向和各公司招聘需求进行调剂。

 

  Q7：已完成简历投递是否可以修改简历或投递岗位？

  投递成功后，可以点击原岗位进行简历内容的修改或更新，但投递岗位和志愿排序无法自行调整。志愿选择及顺序非常重要，请慎重考虑。

# 校招雷达 - Xiaozhao Radar

> 🔍 AI驱动的校招信息聚合平台 —— 856 家央企/互联网大厂/各行业企业校招节点实时抓取，分批加载+分页浏览。

  * 本地代理（推荐，最稳定）：项目根目录已内置 `proxy.js`，一条命令启动，AnySearch 走本地代理（无第三方中转、无公共代理不稳定的问题）：
    
    node proxy.js            # 默认端口 8787，启动后页面自动检测并使用
    node proxy.js 9090       # 自定义端口

  * 自托管 serverless 代理（部署 GitHub Pages 时推荐）：在 `index.html` 顶部 `ANYSEARCH_PROXIES` 数组最前面加你自己的代理地址（如 Vercel/Cloudflare 的 `api/anysearch.js`），或设置浏览器 localStorage 的 `xiaozhao_anysearch_proxy` 覆盖默认列表

### 方式二：BrowserAct 本地 CLI（备用②，专破反爬/验证码）
    
    # 安装 CLI（详见 https://github.com/browser-act/skills）
    npm install -g browser-act
    
    # 登录（免费层需登录账号）
    browser-act login
    
    # 零配置抓取受保护的招聘页
    browser-act stealth-extract "https://join.qq.com/" --out ba_result.json
    
    # 回到雷达页点「📤 导入」选择 ba_result.json

适合被 Firecrawl 拦截、带验证码的站点；`stealth-extract` 免费(登录)即可用。

### 方式三：OpenCLI xiaozhao 适配器（备用③，完整职位库，需登录态）
    
    # 安装 OpenCLI
    npm install -g @jackwener/opencli
    
    # 爬校招数据（复用 Chrome 登录态 + Browser Bridge 插件）
    opencli xiaozhao search "2027 校招" -f json > xiaozhao.json
    
    # 校招雷达点「📤 导入」选 xiaozhao.json

可选参数：`--city 成都` `--degree 本科` `--limit 30`；另有 `opencli xiaohongshu search 校招`、`opencli weibo search 招聘` 适配器。

> 工具选择建议：公开官网批量抓 → 主选 Firecrawl 一键搞定；Firecrawl 失败/限流 → 第一备用 AnySearch（云端免费，自动兜底，无需装任何东西）；站点反爬强/有验证码 → 备用② BrowserAct；需登录态的全量库（如 51job）→ 备用③ OpenCLI。
